# The SWT home of the viewport collections: `org.eclipse.swt.internal.m3.collections`

User (2026-10-19): "if there is a collection that can be extracted from the viewport, let's do that using arrays,
masks and LeetCode", two homes. SWT cannot depend on M3JDK, so this package is a recipe-generated copy of the
viewport collection views of hsoliwal/M3jdk21 `m3/collections` (`com.m3.collections`), themselves extracted by recipe
from this fork's viewport classes (integration round 6 `553eefd41d` and round 10 `5593cc43ba`) and from Nebula Grid.
The code is the same code both ways; the headers differ (Apache-2.0 in `m3/**`, the Synexia dual header here).

## How it is generated (recipe-first; second pass UNCHANGED)

Recipe `com.m3.viewport.recipe.SwtHome` (M3jdk21 `m3/docs/viewport-everywhere/recipe/META-INF/rewrite/m3-swt-home.yml`,
generated by the agent script `swt-home.sh` from the class list): `ChangeType` per class
(`com.m3.collections.X -> org.eclipse.swt.internal.m3.collections.X`), nested-type import rows, the reflective
string literals of the tests, `M3TidyImports`, and `M3ApacheHeader {style: swt}`, which emits the fork's Synexia
header (`C:/m3-superset/tools/SYNEXIA_HEADER.java.txt`) plus one derivation line naming the M3jdk21 commit the sources
came from. Each file's header carries that commit; `PROVENANCE.tsv` lists class, source commit and SHA-256 of the
generated file.

## Adoption (owners switch later, behaviour preserved)

`ADOPTION.tsv` (from M3jdk21 `COLLECTION_EXTRACTION.tsv`): per owner, every method of the viewport mediators that
owns or consumes a collection-shaped algorithm, and the class here it switches onto. TreeViewport, TableViewport,
ListViewport and the Grid are not edited by this branch (BCP: the owners adopt, with their recorded differentials
staying green).

## Example

`examples/org.eclipse.swt.snippets/src/org/eclipse/swt/snippets/m3/M3ViewportFromCollectionsSnippet.java`: a virtual
Table driven by M3FlatteningView -> M3BitMask filter -> M3PermutationIndex sort -> M3RangeSet selection, the same
views as the Swing example in M3jdk21. `--check` runs the model without a Display.
