2. Logical state is authoritative; native/render residency is replaceable.
3. Exposed `Item` facades keep stable identity and are never rebound to another logical coordinate.
4. Viewport work is bounded to visible + overscan ranges where the platform permits.
5. Headers, frozen content, editors, scrollbars and transient feedback are separate z-planes from
   the scrolling body.
6. Native `GC`/`Transform` resources remain paint-call-local; retained graphics state uses
   resource-free affine/geometry/DAG values.
7. Bulk mutation is redraw-bounded and collapse must not manufacture cold virtual facades.
8. Repeated LLM source edits require a reusable Maven/OpenRewrite recipe crate with replay,
   fixed-point and source-drift refusal.
9. `develop`/feature ancestry is preserved; no rebase/force-push is required for this programme.
10. `swt-classic` remains the compatibility escape hatch, not the forward architecture.
